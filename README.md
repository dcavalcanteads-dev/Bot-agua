# 💧 Bot Lembrete de Água (Telegram)

Um bot em Python desenvolvido para enviar lembretes automáticos de hidratação via Telegram em intervalos programados.

## 🚀 Tecnologias Utilizadas

- **Python 3**
- **Requests** (comunicação com a API do Telegram)
- **python-dotenv** (gerenciamento seguro de variáveis de ambiente)

## 📌 Funcionalidades

- Envio periódico de avisos para beber água.
- Leitura segura de tokens e dados sensíveis via arquivo `.env`.
- Hospedagem 24/7 na nuvem.
